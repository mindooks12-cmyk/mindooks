# 숙소 릴스 자막·음성 분석 + 제작 가이드

**음성 추정 근거**
- lolly·jia: 자막이 "~된대요", "사장님이 하나하나"처럼 **말하는 문장을 조각낸 형태**이고, 장면이 바뀔 때마다 이어짐 → 나레이션을 자동 자막으로 만든 전형적인 모양
- sohee: 6~9초로 짧고 자막이 거의 바뀌지 않음, 빠른 유행곡 사용 → 음악만 쓰는 "분위기 컷" 방식

## 2. 두 가지 제작 스타일

### A. 나레이션형 (lolly·jia 방식) ← 처음 시작하기 추천
- 15~20초, AI 음성으로 숙소를 설명하고 자막을 2~4단어씩 띄움
- 장점: 사진/AI 영상만으로 만들 수 있음, 정보 전달이 잘 됨

### B. 음악형 (sohee 방식)
- 6~9초, 가장 예쁜 장면 3~5개 + 유행 음악, 자막은 지명 정도
- 장점: 끝까지 보는 비율이 높아 퍼지기 쉬움
- 단점: **실제로 찍은 좋은 영상**이 있어야 효과가 남. 후킹은 캡션에서 해야 함

## 3. 나레이션형 만드는 순서 (무료 도구 기준)

### ① 대본 쓰기 (15~20초 = 약 60~90자)
```
[후킹 1문장] 낚시 장비 하나 없이 맨손으로 가도
            객실에서 바로 낚시할 수 있는 숙소예요.
[장면 설명 3~4문장] 유리문 열면 바로 낚시터, 사장님이 하나하나 알려주세요.
                  잡은 생선은 회로 떠주시고, 겨울엔 얼음낚시까지 된대요.
[마무리 1문장] 궁금하면 댓글 남겨주세요.
```
후킹 공식은 [jia.travel_.md](jia.travel_.md), [lolly.vely.md](lolly.vely.md) 참고.

### ② AI 음성 만들기
| 도구 | 특징 |
|---|---|
| **캡컷(CapCut)** "텍스트 읽기" | 편집기 안에서 바로 됨. 한국어 여성 목소리 여러 개. 가장 간단 |
| **브루(Vrew)** | 대본 붙여넣으면 AI 음성 + 자막을 한 번에 만들어 줌. 한국어 목소리 많음 |
| **타입캐스트** | 자연스러운 한국어 캐릭터 목소리가 많음 |
| **클로바더빙** (네이버) | 자연스러운 한국어. 무료 버전은 상업적 이용 조건이 있으니 약관 확인 |
| **ElevenLabs** | 가장 자연스러운 편, 한국어 지원 |

목소리 고르는 기준: **20~30대 여성, 밝고 차분한 말투, 속도 1.1~1.2배**. 두 AI 계정의 대본이 "~더라고요", "~된대요" 같은 친구에게 말하는 말투라 여기에 맞는 목소리가 어울림.
⚠️ 무료 요금제는 상업적 이용(협찬·제휴 링크)이 제한되는 경우가 많으니 도구마다 약관을 확인하세요.

### ③ 자막 넣기 (캡컷 기준)
1. 영상 + 음성을 넣고 **텍스트 → 자동 캡션** 실행
2. 한 자막이 **2~4단어(최대 10~12자)**가 되도록 끊기
3. 스타일 설정
   - **위치**: 화면 위에서 30~35% 지점. 아래쪽은 인스타 캡션·버튼에 가려지니 피하기
   - **글자체**: 중간~굵은 고딕 (무료: Pretendard, 에스코어드림, 나눔스퀘어)
   - **색상 (lolly식)**: 흰 글자 + 검정 테두리 2~3 + 약한 그림자
   - **색상 (jia식)**: 흰 글자 + 검정 배경 박스 투명도 30~50%. 밝은 배경에서도 잘 읽힘
   - **크기**: 화면 너비의 50~60% 정도를 차지하는 크기
4. 하나의 스타일을 모든 자막에 적용

### ④ 배경음악
- 인스타에 올릴 때 **인스타 음악 라이브러리**에서 잔잔한 곡 추가 (저작권 문제 없음)
- 음악 볼륨은 나레이션이 잘 들리게 **10~20%**로 낮추기

### ⑤ 썸네일 (lolly식, 선택)
- 첫 장면 위에 두 줄 문구: **윗줄 분홍(#FF8AD8 근처) = 후킹**, **아랫줄 흰색 = 무엇인지**
- 굵고 둥근 글씨 (무료 비슷한 폰트: 여기어때 잘난체, 배민 주아체, Gmarket Sans Bold) + 검정 테두리
- 화면 위쪽 1/3에 배치

## 4. 주의할 점
- AI로 만든 사실적인 영상은 인스타에서 **AI 표시**를 해야 함 (두 AI 계정도 표시돼 있음)
- AI 영상이 실제 숙소와 많이 다르면 신뢰를 잃을 수 있음. 가격·시설 정보는 실제와 맞게
- 폰트도 무료라도 **상업적 이용 가능 여부**를 확인하고 쓰기
